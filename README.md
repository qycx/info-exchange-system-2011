- 语言：C / C++（含少量 Perl 脚本 `.pl`、资源 `.rc`/`.rc2`、清单 `.xml`）
- 工具链：Visual C++，工程同时保留 **VS2008（`.sln`/`.vcproj`/`.dsp`）** 与 **VS2010（含 `2010` 字样的 `.sln`）** 方案文件

- 构建产物类型：DLL / EXE / 守护进程 / 资源工程等
